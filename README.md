## Пример кода

Программа, которая берёт два числа и показывает все основные операции с ними:

```csharp
int x = 10;
int y = 3;
Console.WriteLine(x + y);
Console.WriteLine(x - y);
Console.WriteLine(x * y);
Console.WriteLine(x / y);
Console.WriteLine(x % y);
```

## Выводы

**Про .NET** Это платформа, на которой работают программы на C#. Код сначала компилируется в промежуточный IL-код, а потом CLR запускает его на любой системе - Windows, Linux или macOS. Именно поэтому программы на C# переносимы.

**Про типы** В C# тип переменной задаётся один раз и не меняется. Если объявил `int`, то там всегда будет целое число. `var` - это не отдельный тип, а просто способ не писать тип руками, компилятор сам его выведет, но зафиксирует навсегда.

**Про Git** Git хранит историю изменений проекта, а GitHub — это удалённое хранилище, куда проект отправляется, чтобы был доступен с любого компьютера и другим людям.

| Характеристика | C# / .NET |
| :--- | :--- |
| **Платформа** | .NET (CLR) |
| **Компиляция** | C# → IL-код → машинный код |
| **Запуск** | `dotnet run` |
| **Тип переменной** | Указывается явно: `int x = 5;` |
| **Вывод в консоль** | `Console.WriteLine("текст")` |
| **Ввод от пользователя** | `Console.ReadLine()` |
| **Интерполяция строк** | `$"Привет, {name}!"` |
| **Целочисленное деление** | `10 / 3 = 3` |
| **Дробное деление** | `(double)10 / 3 = 3.333...` |
| **Математические функции** | `Math.Abs(), Math.Pow(), и др.` |

## Ответы на вопросы

**1.** `Write` печатает текст и не переносит строку, а `WriteLine`  переносит. То есть после `WriteLine` следующий вывод начнётся с новой строки.

**2.** Будет ошибка. `int` хранит только целые, а `3.14` это дробное. Для дробных нужен `double`.

**3.** Потому что оба числа целые, а C# при делении целых отбрасывает дробную часть. Чтобы получить дробь, надо, чтобы хотя бы одно число было `double`: например, `10.0 / 4`.

**4.** `var` - это просто сокращение. Компилятор смотрит на значение справа и сам решает, какой тип поставить. Но тип фиксируется один раз и не меняется. В Python переменная может менять тип когда угодно, а в C# нет.
